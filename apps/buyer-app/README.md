# Buyer Android Application (`apps/buyer-app`)

## Planned Technology
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Riverpod
- **Routing:** GoRouter
- **HTTP Client:** Dio
- **Authentication:** Firebase Authentication
- **Notifications:** Firebase Cloud Messaging (FCM)
- **Maps:** flutter_map (OpenStreetMap)

## Role in Architecture
The Buyer Mobile Application enables institutional and commercial buyers to:
- Register and maintain buyer business profiles and delivery addresses
- Post commodity requirements (crop, variety, grade, required quantity, target delivery date)
- Discover and match with available verified farmer supply
- Place and track orders through live status progression
- Confirm delivery and receive invoices/receipts

> **Phase 0 Notice:** No screens, widgets, state management, or API integrations are implemented at this stage. Implementation will begin in Phase 4 as specified in `Goal.md`.
