# Admin Web Panel (`apps/admin`)

## Planned Technology
- **Framework:** React
- **Language:** TypeScript
- **Build Tool:** Vite
- **Styling:** Tailwind CSS + shadcn/ui
- **Data Fetching:** TanStack Query (React Query)
- **Mapping:** Leaflet
- **Charts:** Recharts

## Role in Architecture
The Admin Web Panel is the central operations hub for administrators to:
- Monitor the end-to-end supply chain lifecycle
- Verify farmers, buyers, drivers, and vehicles
- Supervise supply-demand matching and order fulfillment
- Track logistics, pickup schedules, and near real-time driver locations
- Manage crop catalogs, pricing, weather alerts, system settings, and audit logs

> **Phase 0 Notice:** No UI components, tables, routes, dashboards, or business modules are implemented at this stage. Implementation will begin in Phase 2 as specified in `Goal.md`.
