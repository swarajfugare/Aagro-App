# Farmer Android Application (`apps/farmer-app`)

## Planned Technology
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Riverpod
- **Routing:** GoRouter
- **HTTP Client:** Dio
- **Authentication:** Firebase Authentication
- **Notifications:** Firebase Cloud Messaging (FCM)
- **Maps:** flutter_map (OpenStreetMap)

## Role in Architecture
The Farmer Mobile Application enables farmers to:
- Register and maintain farmer/farm profiles
- Track crops, sowing dates, and harvest projections
- Declare available supply (quantity, grade, availability date, photos)
- View matched buyer requirements and scheduled pickups
- Check market prices, price trends, and localized weather advisories

> **Phase 0 Notice:** No screens, widgets, state management, or API integrations are implemented at this stage. Implementation will begin in Phase 3 as specified in `Goal.md`.
