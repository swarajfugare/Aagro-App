# Driver Android Application (`apps/driver-app`)

## Planned Technology
- **Framework:** Flutter
- **Language:** Dart
- **State Management:** Riverpod
- **Routing:** GoRouter
- **HTTP Client:** Dio
- **Authentication:** Firebase Authentication
- **Notifications:** Firebase Cloud Messaging (FCM)
- **Maps & Navigation:** flutter_map (OpenStreetMap) + Geolocator

## Role in Architecture
The Driver Mobile Application enables transport partners to:
- Manage driver verification and registered vehicle capacities
- Receive assigned trips with optimized multi-stop pickup routes
- Confirm farm pickups with quantity verification and evidence capture
- Prevent overloading by enforcing vehicle capacity limits
- Execute buyer deliveries with Proof of Delivery (POD) uploads
- Track periodic GPS location updates to the backend API

> **Phase 0 Notice:** No screens, widgets, state management, or API integrations are implemented at this stage. Implementation will begin in Phase 7 as specified in `Goal.md`.
