# Shared Utils Package (`packages/shared-utils`)

## Purpose
This package is reserved for generic reusable utility functions, date/time formatting, coordinate calculations, mathematical helpers, and validation utilities.

### Future Scope
- Geolocation distance calculation helpers (Haversine formula)
- Unit conversions (e.g., Quintal, Metric Ton, Kilogram, Acre, Hectare)
- Currency and date formatting helpers
- Standardized error parsing utilities

> **Phase 0 Notice:** No code is implemented at this stage. Utilities will be implemented only as common requirements arise across modules.
