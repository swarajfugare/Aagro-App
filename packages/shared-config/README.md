# Shared Config Package (`packages/shared-config`)

## Purpose
This package is reserved for shared configuration conventions, constants, environment schema validators, and cross-application standard defaults.

### Future Scope
- Shared system constants (e.g., supported crops, grade definitions, units of measurement)
- Common ESLint, Prettier, and TypeScript configuration bases
- Map provider configurations and default tile endpoints

> **Phase 0 Notice:** No code is implemented at this stage. Configuration standards will be introduced in subsequent development phases.
