# Shared Types Package (`packages/shared-types`)

## Purpose
This package is reserved for shared TypeScript type definitions, DTO interfaces, enum declarations, and domain entity contracts used across the backend and web frontend applications.

### Future Scope
- Shared API request/response types
- User roles and permission enum definitions
- Supply, demand, order, and trip status state machine types
- Common pagination and API envelope formats

> **Phase 0 Notice:** No code is implemented at this stage to prevent premature coupling. Definitions will be added as backend and frontend contracts are established.
